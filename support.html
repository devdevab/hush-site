Common questions

How do I add music? Choose Add Folder in the File menu (⇧⌘O), or drag songs and folders onto the window.

Is playback bit-perfect? Yes, when the EQ is off (preset 1, Flat), volume is at 100% and balance is centred. Hush switches your output device to each song's sample rate.

A song won't play. Make sure the file is still in the same place. Use REM ▸ Remove Missing Files to clean up the playlist.

Keyboard shortcuts? Help ▸ Keyboard Shortcuts lists them all.
